## 📌 Descripción General
Este repositorio centraliza los proyectos, prácticas y apuntes desarrollados a lo largo de la materia **Programación III**. El objetivo principal es consolidar el desarrollo web moderno abarcando desde las bases fundamentales de la web hasta arquitecturas avanzadas del lado del cliente y del servidor con TypeScript.

---

## 📖 Conceptos Clave de la Materia

* **HTML (HyperText Markup Language):** Lenguaje de marcado estándar utilizado para estructurar y desplegar el contenido de las páginas web (textos, imágenes, formularios).
* **CSS (Cascading Style Sheets):** Lenguaje de diseño gráfico para estructurar la presentación y apariencia visual de los elementos HTML (colores, fuentes, layouts responsivos).
* **JavaScript:** Lenguaje de programación interpretado que añade interactividad, lógica y dinamismo a las páginas web en el lado del cliente.
* **TypeScript:** Un superconjunto tipado de JavaScript que añade tipado estático opcional y características avanzadas para mejorar la escalabilidad y mantenimiento del código.
* **React.js:** Una biblioteca de JavaScript de código abierto desarrollada por Meta para construir interfaces de usuario basadas en componentes reutilizables y de alto rendimiento.
* **NestJS:** Un framework progresivo de Node.js diseñado para construir aplicaciones del lado del servidor (backend) altamente escalables y eficientes, utilizando TypeScript y arquitectura modular inspirada en Angular.
