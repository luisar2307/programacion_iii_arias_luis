## Contenido de la materia

### HTML

HTML (HyperText Markup Language) es el lenguaje de marcado que estructura el contenido de una página web. Mediante etiquetas define títulos, párrafos, listas, enlaces, imágenes, tablas, formularios y elementos multimedia como audio y video.

### CSS

CSS (Cascading Style Sheets) es el lenguaje de hojas de estilo que controla la apariencia de una página HTML: colores, fondos, tamaños, márgenes, bordes y la forma en que se organizan los elementos.

### JavaScript

JavaScript es un lenguaje de programación que da interactividad a las páginas web. Permite responder a las acciones del usuario, modificar el contenido de la página y trabajar con datos tanto en el navegador como en el servidor.

### TypeScript

TypeScript es una extensión de JavaScript que agrega tipado estático. Al indicar el tipo de cada dato, ayuda a detectar errores antes de ejecutar el programa y hace que el código sea más claro y fácil de mantener.

### NestJS

NestJS es un framework de Node.js para construir aplicaciones de servidor (backend) ordenadas y escalables. Está hecho con TypeScript y organiza el código en módulos, controladores y servicios.

### ReactJS

ReactJS es una librería de JavaScript para construir interfaces de usuario a partir de componentes reutilizables. Permite crear aplicaciones web dinámicas que se actualizan de forma eficiente.
